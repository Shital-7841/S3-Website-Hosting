\# Automated Static Website Hosting Using AWS SDK



\## Project Overview

This project hosts a static website on Amazon S3 and uploads website files automatically using Python and Boto3.



\## AWS Services

\- Amazon S3

\- AWS IAM

\- AWS SDK for Python (Boto3)



\## Technologies

\- Python

\- HTML

\- JavaScript

\- Boto3



\## Features

\- Static website hosting

\- Automated file uploads

\- Public website access

\- Interactive button



\## Live Website

http://s3-website-shital-959590.s3-website.ap-south-1.amazonaws.com



\## Run the Project

1\. Install Boto3: `pip install boto3`

2\. Configure AWS CLI credentials.

3\. Run: `python upload\_website.py s3-website-shital-959590`



\## Security

This demo website is public. Never upload AWS credentials, passwords, or private information.
